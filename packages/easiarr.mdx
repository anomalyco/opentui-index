easiarr guides users through Docker Compose setup for Radarr, Sonarr, Prowlarr,
and other media applications. It generates the Compose file and stores its
configuration in the XDG configuration directory.

The OpenTUI terminal interface also manages applications and containers. It
can show container logs, configure reverse proxies, and apply TRaSH Guides
profiles.

The [README](https://github.com/muhammedaksam/easiarr#readme) documents the
setup flow, supported applications, requirements, and configuration files.
