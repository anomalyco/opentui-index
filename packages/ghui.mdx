ghui uses [OpenTUI React](/packages/opentui-react) to show GitHub pull requests
from multiple repositories. Users can inspect details and diffs, write
comments, and manage labels.

The application can submit reviews, change draft status, merge pull requests,
and show GitHub Actions runs. It also opens pull requests in an editor or
browser.

The [README](https://github.com/kitlangton/ghui#readme) documents
configuration, editor commands, workflow views, and key bindings.
