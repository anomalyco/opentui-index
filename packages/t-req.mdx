t-req uses [OpenTUI Solid](/packages/opentui-solid) to browse `.http` files,
run requests, and inspect responses in a terminal interface.

The application can also run scripts and tests, switch between profiles, and
show observed requests as they occur.

The [documentation](https://t-req.io/docs/getting-started) explains projects,
the terminal interface, command-line use, configuration, and the HTTP file
format.
