Red uses [OpenTUI React](/packages/opentui-react) to inspect and manage Redis
databases. Its terminal interface groups keys by a configurable delimiter and
shows key details.

Users can set the Redis connection, initial path, automatic refresh, and refresh
interval. Red accepts command-line options, environment variables, and several
configuration file formats.

The [README](https://github.com/evertdespiegeleer/red-cli#readme) documents
usage and configuration.
