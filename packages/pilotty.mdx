pilotty gives AI agents command-line control of OpenTUI and other terminal
applications. It manages PTY sessions and returns screen state as structured
data.

The tool supplies keyboard and mouse input, terminal snapshots, text waits, and
concurrent sessions. Its daemon keeps applications active between command
invocations.

pilotty supports Linux and macOS on x64 and ARM64 systems. It does not support
Windows because it uses Unix sockets and POSIX PTY interfaces.

The [README](https://github.com/msmps/pilotty#readme) documents commands,
session behavior, terminal input, and AI agent workflows.
