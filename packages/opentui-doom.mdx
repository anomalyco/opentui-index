DOOM runs doomgeneric as WebAssembly and draws its framebuffer with half-block
terminal cells. It supports keyboard controls, mouse aiming, and persistent
save files.

The application requires Bun and a user-supplied DOOM WAD file. Sound effects
and music require `mpv`. The npm package includes the compiled WebAssembly
module.

The project [README](https://github.com/muhammedaksam/opentui-doom#readme)
documents setup, controls, save files, sound, and known input limits.
