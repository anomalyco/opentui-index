WAHA TUI manages WhatsApp through a WAHA server. Users can manage sessions,
browse chats, and send or receive messages from the terminal.

The application supports search, polls, link previews, message actions, and
desktop notifications. WebSocket events update messages, reactions, labels,
polls, and typing indicators.

The [README](https://github.com/muhammedaksam/waha-tui#readme) documents WAHA
configuration, keyboard controls, and the WEBJS engine setting.
