termcn provides free and open-source terminal UI components for React. It is
the terminal equivalent of shadcn/ui, offering ready-to-use, customizable
components with zero configuration.

The CLI scaffolds projects, installs components from registries, and builds
registries. It supports the OpenTUI rendering framework and ships 38 built-in
themes including Catppuccin, Dracula, Nord, and Tokyo Night.

Use `npx termcn init` to scaffold a terminal project and `npx termcn add button`
to install themed, framework-specific terminal UI components. The MCP server
enables AI-assisted component discovery and installation.
