termcn brings ready-to-use terminal UI components to React applications through
OpenTUI. It follows the same registry and installation pattern as shadcn/ui for
the web, adapted for the terminal.

The CLI scaffolds a project, installs components from a registry, and builds
custom registries. Thirty-eight built-in themes ship with the components,
including Catppuccin, Dracula, Nord, and Tokyo Night.

An MCP server integrates with AI coding tools for component discovery and
installation. The [installation guide](https://termcn.dev/docs/installation)
covers setup and the available commands.
