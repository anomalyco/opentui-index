OpenCode is an open source agent that helps you write code in your terminal,
IDE, or desktop.

The terminal interface uses OpenTUI. The project also has a desktop application
and extensions for several code editors.

The CLI supports macOS, Linux, and Windows. Terminal use requires a modern
terminal emulator and credentials for the selected model provider.

The [documentation](https://opencode.ai/docs/) explains setup, providers,
agents, tools, and terminal commands.
