otel-tui receives OpenTelemetry data from your services and shows it in the
terminal, with no collector or backend to run. Point an OTLP exporter at port
4318 for HTTP or 4317 for gRPC.

It shows each service's rate, errors, and latency percentiles, traces as span
waterfalls, metric series with exemplars, and logs linked to their traces. It
is built with [OpenTUI React](/packages/opentui-react).

otel-tui runs on macOS and Linux. The first run downloads the DuckDB OTLP
extension, so it needs network access once. The receiver has no
authentication and listens on 127.0.0.1 unless you set `--host`.

The [README](https://github.com/michaltarasiuk/otel-tui#readme) describes each
view and its keys.
